安装 Charstle 根证书

用于解密此设备经代理发出的 HTTPS 流量

iOS / iPadOS 描述文件 下载证书（.crt） 下载证书（.pem）

安装步骤

iOS / iPadOS
  1. 使用 Safari 点击上方「描述文件」并允许下载
  2. 设置 → 通用 → VPN 与设备管理，安装 Charstle Root CA
  3. 设置 → 通用 → 关于本机 → 证书信任设置，打开完全信任
Android
  1. 下载 .crt
  2. 设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书
  3. Android 7+ 的 App 默认不信任用户证书，需要 App 在 network_security_config 中声明
Windows / macOS
  1. Windows：双击 .crt → 安装到「受信任的根证书颁发机构」
  2. macOS：双击 .pem 导入钥匙串，并设为「始终信任」
安全提示：只在你自己的设备上安装。调试结束后可在系统设置中删除或关闭信任。
